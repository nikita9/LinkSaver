# Security Policy

## Supported versions

Security fixes are provided for the latest released version of Link Saver.

| Version | Supported |
| --- | --- |
| 2.1.x | Yes |
| 2.0.x and earlier | No |

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/nikita9/LinkSaver/security/advisories/new). Include reproduction steps, affected versions, and expected impact when possible. Do not open a public issue for an undisclosed vulnerability.

Please avoid including real bookmark collections, credentials, or other personal data in a report. You should receive an acknowledgement within seven days. We will coordinate validation, remediation, and disclosure through the private advisory.

## Scope

Security reports may cover the Electron application, import/export handling, local storage, release automation, and distributed installers. Reports that require a user to disable operating-system security protections should clearly state that prerequisite.
