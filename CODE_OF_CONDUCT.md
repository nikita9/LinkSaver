# Code of Conduct

## Our standards

Link Saver contributors are expected to communicate respectfully, welcome constructive feedback, focus criticism on the work, and help keep project spaces safe and inclusive.

Unacceptable behavior includes harassment, discrimination, threats, deliberate intimidation, publishing another person's private information, and sustained disruption of project discussions.

## Enforcement

Maintainers may edit or remove contributions and may temporarily or permanently restrict participation when behavior is inappropriate, threatening, or harmful.

Report conduct concerns privately to the maintainer through [the @nikita9 GitHub profile](https://github.com/nikita9). Do not publish personal or sensitive details in a public issue. Reports will be reviewed as promptly and impartially as possible, with privacy respected to the extent practical.

## Scope

This code applies in repository spaces and when someone is officially representing the project in public spaces.
